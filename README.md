## 🚀 Featured Project

### 🚗 [Fleet — Real-Time Vehicle Tracking Demo](https://github.com/tejashr0716/fleet)

A personal full-stack project for vehicle telemetry and geospatial tracking, built with **Python, FastAPI, PostgreSQL, Redis, and WebSockets**.

- **REST APIs** for vehicle registration, GPS ingestion, position history, geofences, and alerts
- **JWT authentication** and authenticated WebSocket updates
- **PostgreSQL-backed telemetry history** and transactional outbox events
- **Redis caching, geospatial queries, and Pub/Sub** for live delivery
- **Dashboard** with map visualization and telemetry charts
- **Docker Compose setup**, unit tests, and integration tests

> **Demo scope:** GPS data is synthetic. The public showcase uses browser fixtures; the full backend runs separately. This is a demonstration project, not a production vehicle deployment.
